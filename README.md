# KakaoTalk Perfect AdBlocker

Windows용 카카오톡 PC 광고 차단 도구입니다.

카카오톡 PC 버전에서 보이는 하단 배너 광고와 팝업 광고를 줄이고, 광고가 사라진 뒤 남는 빈 영역까지 자동으로 숨겨 더 깔끔한 화면을 만들어 줍니다.

> 이 프로젝트는 카카오톡 공식 앱이 아니며, 카카오톡 업데이트로 창 구조가 바뀌면 동작 방식이 달라질 수 있습니다.

## 주요 기능

- 광고 도메인을 `hosts` 파일로 차단합니다.
- 카카오톡 창 안에 남는 광고용 빈 영역을 백그라운드 스크립트가 숨깁니다.
- 카카오톡 메인 창이 닫혀 있거나 트레이에 있어도 우측 하단 팝업 광고를 감지해 숨기고 닫습니다.
- 새 광고 창 표시 이벤트를 즉시 받아 처리하므로 주기 검사만 사용할 때보다 팝업이 화면에 보이는 시간이 훨씬 짧습니다.
- `setup_adblock.bat` 실행 한 번으로 스크립트를 시작 프로그램에 등록하고 바로 실행합니다.
- 별도 Python 패키지를 설치하지 않습니다. Python 표준 라이브러리만 사용합니다.

## 지원 환경

- Windows
- 카카오톡 PC 버전
- Python 3.x

Python을 설치할 때는 반드시 **Add Python to PATH** 옵션을 체크해 주세요. 시작 프로그램 바로가기가 `pythonw.exe`로 실행되기 때문에 PATH 등록이 필요합니다.

## 설치 방법

### 1. 파일 다운로드

GitHub의 **Code > Download ZIP**으로 내려받거나, Git을 사용한다면 아래 명령으로 받을 수 있습니다.

```powershell
git clone https://github.com/spidychoipro/KakaoTalk-Perfect-AdBlocker.git
```

다운로드한 ZIP 파일은 압축을 풀어 주세요.

### 2. 자동 실행 등록

압축을 푼 폴더에서 `setup_adblock.bat`를 더블 클릭합니다.

이 배치 파일은 다음 작업을 수행합니다.

- `kakaotalk_adblock.py`를 `%USERPROFILE%\KakaoAdBlock` 폴더로 복사
- 기존에 실행 중이던 예전 광고 차단 프로세스 종료
- Windows 시작 프로그램 폴더에 `KakaoAdBlock.lnk` 바로가기 생성
- 새 광고 차단 스크립트 즉시 실행
- 다음 로그인부터 광고 영역 숨김 스크립트 자동 실행

이미 예전 버전을 설치했다면 최신 파일을 받은 뒤 `setup_adblock.bat`를 다시 실행해 주세요. 그래야 `%USERPROFILE%\KakaoAdBlock` 안의 백그라운드 스크립트가 새 버전으로 교체됩니다.

### 3. 광고 도메인 차단

`hosts` 파일 수정은 관리자 권한이 필요합니다.

1. 메모장을 **관리자 권한으로 실행**합니다.
2. `C:\Windows\System32\drivers\etc\hosts` 파일을 엽니다.
3. 파일이 보이지 않으면 우측 하단 파일 형식을 **모든 파일**로 변경합니다.
4. 이 저장소의 `hosts_entries.txt` 내용을 복사해 `hosts` 파일 맨 아래에 붙여넣습니다.
5. 저장합니다.

### 4. 카카오톡 재시작

카카오톡을 완전히 종료한 뒤 다시 실행합니다.

트레이 아이콘에 남아 있을 수 있으니, 작업 표시줄 오른쪽 아래의 카카오톡 아이콘까지 종료한 후 다시 켜는 것을 권장합니다.

## 동작 방식

이 프로젝트는 두 가지 방식으로 광고를 줄입니다.

| 구성 파일 | 역할 |
| --- | --- |
| `hosts_entries.txt` | 알려진 카카오톡 광고 도메인을 `127.0.0.1`로 돌려 광고 데이터를 받지 못하게 합니다. |
| `kakaotalk_adblock.py` | Windows 창 API와 창 표시 이벤트 훅을 사용해 카카오톡 하단 배너와 우측 하단 팝업 광고 창을 찾아 숨기거나 닫습니다. |
| `setup_adblock.bat` | Python 스크립트를 사용자 폴더로 복사하고 시작 프로그램에 등록한 뒤 즉시 실행합니다. |

## 삭제 방법

더 이상 사용하지 않으려면 아래 순서대로 정리하면 됩니다.

1. `Win + R`을 누르고 `shell:startup`을 입력합니다.
2. `KakaoAdBlock.lnk` 바로가기를 삭제합니다.
3. `%USERPROFILE%\KakaoAdBlock` 폴더를 삭제합니다.
4. 관리자 권한 메모장으로 `hosts` 파일을 열어 `hosts_entries.txt`에서 추가했던 줄을 삭제합니다.
5. 카카오톡을 재시작합니다.

## 문제 해결

### `pythonw.exe`를 찾을 수 없다고 나올 때

Python이 PATH에 등록되지 않은 상태입니다. Python 설치 프로그램을 다시 실행하고 **Add Python to PATH**를 체크한 뒤 설치를 완료해 주세요.

### 광고가 계속 보일 때

- `hosts` 파일이 관리자 권한으로 저장되었는지 확인해 주세요.
- `hosts_entries.txt`의 내용이 `hosts` 파일 맨 아래에 들어갔는지 확인해 주세요.
- 카카오톡을 트레이 아이콘까지 완전히 종료한 뒤 다시 실행해 주세요.
- 예전 버전이 설치되어 있었다면 최신 파일로 받은 뒤 `setup_adblock.bat`를 다시 실행해 주세요.
- 진단이 필요하면 터미널에서 `python kakaotalk_adblock.py --once --debug`를 실행하면 감지 결과를 볼 수 있습니다.
- 팝업이 아주 짧게 보였다가 사라지는 경우에는 `setup_adblock.bat`를 다시 실행해 최신 이벤트 훅 방식이 설치된 상태인지 확인해 주세요.

### 카카오톡 업데이트 후 다시 보일 때

카카오톡 업데이트로 창 구조나 광고 도메인이 바뀌면 기존 방식이 맞지 않을 수 있습니다. 이 경우 저장소의 최신 버전을 받아 다시 적용해 주세요.

## 참고

일부 백신이나 보안 프로그램은 `hosts` 파일 변경을 경고할 수 있습니다. 이 저장소의 `hosts_entries.txt`는 광고 도메인을 로컬 주소로 돌리는 용도입니다. 적용 전에 내용을 직접 확인해도 됩니다.

개인 사용을 위해 만든 작은 도구지만, 카카오톡 PC 광고 때문에 불편했던 분들께 도움이 되었으면 좋겠습니다.
