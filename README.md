
# 카톡 PC버전 광고 싹 다 없애기 (2026 최신)

카톡 PC버전 쓸 때마다 밑에 뜨는 배너랑 오른쪽 밑에 갑툭튀하는 팝업 광고 때문에 짜증나서 직접 만들었습니다.  
단순히 광고 데이터만 안 불러오는 게 아니라, 광고가 있던 **하얀 빈 공간까지 싹 숨겨서** 깔끔하게 만들어줍니다.

## 🔥 주요 기능
- **광고 데이터 차단:** 광고 서버 통신 자체를 막아버립니다.
- **빈칸 숨기기:** 광고가 빠진 자리에 생기는 흉한 하얀 칸을 실시간으로 숨겨줍니다.
- **자동 실행:** 한 번만 설정하면 컴퓨터 켤 때마다 알아서 실행됩니다.

## 🛠 설치 방법 (진짜 쉬움)

### 1. 파이썬 설치
- 컴퓨터에 파이썬이 깔려 있어야 합니다. [python.org](https://www.python.org/)에서 받으세요.
- **설치할 때 'Add Python to PATH' 꼭 체크하셔야 합니다!**

### 2. 파일 내려받고 실행하기
1. [Release](https://github.com/spidychoipro/KakaoTalk-Perfect-AdBlocker/releases)에서 파일을 받거나 코드를 다운로드합니다.
2. `setup_adblock.bat` 파일을 그냥 더블 클릭해서 실행하세요.
   - 알아서 필요한 곳으로 파일을 옮기고 시작 프로그램으로 등록해 줍니다.

### 3. 광고 서버 차단 (이걸 해야 완벽함)
1. **메모장**을 마우스 우클릭해서 **[관리자 권한으로 실행]** 합니다.
2. `C:\Windows\System32\drivers\etc\hosts` 파일을 엽니다. (안 보이면 우측 하단 '모든 파일'로 변경)
3. `hosts_entries.txt` 안에 있는 내용을 복사해서 맨 밑에 붙여넣고 저장하세요.

### 4. 카톡 재시작
- 카톡을 완전히 껐다가(트레이 아이콘까지) 다시 켜면 끝입니다.

## 📌 참고사항
- 카톡이 대규모 업데이트를 해서 창 구조가 바뀌면 작동이 안 될 수 있습니다. 그럴 땐 제가 업데이트해서 다시 올릴 테니 여기 와서 확인해 주세요.
- 백신에서 hosts 파일 바꾼다고 경고 뜰 수 있는데, 광고 서버 주소만 막는 거니까 안심하고 쓰셔도 됩니다.

개인적으로 쓰려고 만든 거라 부족할 수 있지만, 광고 때문에 고통받는 분들께 도움이 됐으면 좋겠네요!
