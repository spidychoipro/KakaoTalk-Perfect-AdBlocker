
# KakaoTalk-Perfect-AdBlocker (2026 최신 버전)

카카오톡 PC 버전의 광고를 완벽하게 차단하고, 광고 영역(빈 칸)까지 숨겨주는 도구입니다.

## ✨ 기능
- **광고 서버 차단:** DNS 수준에서 광고 데이터를 원천 봉쇄합니다.
- **광고 영역 숨기기:** 실시간으로 카카오톡 창을 감시하여 광고가 들어가는 빈 공간을 숨깁니다.
- **자동 실행:** 윈도우 시작 시 자동으로 실행되어 신경 쓸 필요가 없습니다.

## 🚀 아주 쉬운 설치 방법 (컴맹용)

### 1단계: 필수 프로그램 설치
- 컴퓨터에 **Python**이 설치되어 있어야 합니다. (설치 시 'Add Python to PATH' 체크 필수!)

### 2단계: 파일 다운로드 및 실행
1. 이 저장소의 **Release** 탭에서 최신 파일을 다운로드하거나, 전체 코드를 다운로드합니다.
2. `setup_adblock.bat` 파일을 더블 클릭하여 실행합니다.
   - 이 과정에서 시작 프로그램 등록이 자동으로 완료됩니다.

### 3단계: 광고 서버 차단 (가장 중요!)
1. **메모장**을 마우스 우클릭하여 **[관리자 권한으로 실행]**합니다.
2. `파일` -> `열기`를 누르고 다음 경로를 입력합니다: `C:\Windows\System32\drivers\etc`
3. 우측 하단의 파일 형식을 `모든 파일(*.*)`로 바꾸고 `hosts` 파일을 엽니다.
4. `hosts_entries.txt` 파일에 적힌 내용을 맨 아래에 복사해서 붙여넣고 저장합니다.

### 4단계: 적용 확인
- 카카오톡을 완전히 종료했다가 다시 켜보세요. 광고가 사라진 것을 확인할 수 있습니다!

## 🛠 사용된 파일
- `kakaotalk_adblock.py`: 실시간 광고창 숨기기 스크립트
- `setup_adblock.bat`: 자동 설치 및 시작 프로그램 등록 파일
- `hosts_entries.txt`: hosts 파일에 추가할 차단 목록

## ⚠️ 주의사항
- 카카오톡 업데이트 시 광고창의 구조가 바뀌면 작동하지 않을 수 있습니다. 그럴 경우 이 저장소의 업데이트를 확인해 주세요.
- 백신 프로그램에서 `hosts` 파일 수정을 경고할 수 있으나, 이는 안전한 광고 차단 과정입니다.
